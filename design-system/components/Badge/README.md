# Badge

A small label for a service category or a job status: `.np-badge`, optionally `--lichen`, `--success`, `--warning` or `--danger`.

- Neutral for service categories (Roofing, Windows, Siding).
- `--lichen` for offers ("Free estimate").
- Status tones always carry a word, and usually the `.np-badge__dot`; color is never the only signal. Success is rain blue, not green.

Consumer provides: one or two words of text, sentence case.
