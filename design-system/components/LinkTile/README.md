# LinkTile

The Linktree row: a glass, cream-outlined link that sits on the fog-pines photo. `.np-tile` with `__icon`, `__label` and `__arrow` parts.

Use it for short link lists on the photo: the home page "Quick links", a contact page, or a bio-link page. Place tiles inside a `.np-photo` section that has `data-theme="dark"` and the fog-pines photo as its background image; stack them 12px apart (`space-3`), max 440px wide, centered.

Consumer provides: the href, a 2–5 word label, and an optional 20px icon in `__icon`.

Don't: use tiles on plain surfaces (use Button or ProjectCard), or put more than six in one stack.
